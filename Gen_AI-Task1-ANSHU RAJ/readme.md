# GenAI Task - Product Inventory Assignment

## Overview

This project demonstrates the use of fundamental Python data structures including lists, tuples, sets, and dictionaries.

## Tasks Completed

### Task 1 - Lists and Tuples
- Created a list containing product names.
- Created a sample product tuple containing name, price, and category.
- Accessed the second and last products.
- Added two new products to the list.

### Task 2 - Sets
- Created a set containing product categories.
- Added a new category.
- Demonstrated that duplicate categories are ignored.
- Checked whether a category exists in the set.

### Task 3 - Dictionaries
- Created a dictionary containing product prices.
- Added a new product and price.
- Updated an existing product price.
- Removed a product.
- Handled a product that does not exist.
- Calculated the average product price.
- Found the most expensive and cheapest products.

### Task 4 - Catalog
- Created a catalog using a list of tuples.
- Created a category-to-products dictionary.
- Found the category containing the maximum number of products.

## Technologies Used
